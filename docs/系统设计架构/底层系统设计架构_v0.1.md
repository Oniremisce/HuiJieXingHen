# 《汇界星痕》底层系统设计架构 · v0.1

> 定位：描述各系统的设计规格与接口边界，供后续拆任务卡时引用，不替代推进表的任务卡定义。
> 对齐基线：T0.1\~T2.1 全部已交付（工程骨架、数据模型、CSV 管线、事件总线、Y-sort 等距、交互系统、队伍系统、三觉醒者数据）。

***

## 一、渲染层

### 1.1 地图视角与风格

| 项              | 规格                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------- |
| 视角             | 2.5D 斜向等距，tile 64×32，TILE\_LAYOUT\_DIAMOND\_RIGHT（与 T1.1 一致）                                 |
| 风格参照           | 棕色尘埃2：地表材质分层、装饰密度、建筑体块化（2\~3 层高度）、整体 Q 版                                                     |
| 高差表现           | MVP 内营地与首关接入「高层 tile + 侧面深度贴图」，配合 Y-sort 形成前后景深；后续区域逐替换                                      |
| 氛围光            | CanvasModulate 区域色温 + 少量点光源（篝火/结晶发光）；昼夜循环为后续扩展                                               |
| 渲染层级（Y-sort 链） | 根 Node2D → Ground(TileMapLayer) / Decorations / 角色容器 → 全部 y\_sort\_enabled=true，叶子按全局 Y 统一排序 |

**交叉引用**：T1.1 TileSet 规格、T1.2 Y-sort 链式合并规则。

### 1.2 角色地图表现

#### 8 方向动画

| 状态      | 规格                                                |
| ------- | ------------------------------------------------- |
| 方向数     | 屏幕空间 8 方向，每方向独立姿势组（斜向为独立资源，非左右翻转）                 |
| Idle 呼吸 | 4 帧循环 \~3s                                        |
| Walk 移动 | 6\~8 帧循环 \~0.6s                                   |
| 切换      | 待机↔移动为帧动画切换，现有 PlayerController 呼吸占位走 Sprite 接口替换 |

#### 遮挡描边

| 项  | 规格                                                                            |
| -- | ----------------------------------------------------------------------------- |
| 触发 | 前景元素 origin 全局 y > 角色脚部 y 且投影重叠（复用 Y-sort 排序数据，无需射线）                          |
| 效果 | 纯白 1.5\~2px 外描边，随遮挡面积淡入淡出                                                     |
| 适用 | 玩家与 NPC 均适用                                                                   |
| 实现 | 角色 Sprite 在被遮挡时切换 shader（CanvasItem.material，方案：单材质双 pass 或根据遮挡状态切换 material） |

**交叉引用**：T1.3 PlayerController 走停切换、T1.2 Y-sort origin 取脚部。

### 1.3 角色在地图的存在规则

- 地图上**仅主角渲染与移动**，心契同行角色不跟随、不出现在地图
- 心契角色存在感落在：编队/角色列表 UI、战斗出场、心契专属对话与任务标记
- 该规则简化了 T2.2 Party 设计（同行槽位只占编队，不生成地图实体）

### 1.4 场景流转

| 项    | 规格                              |
| ---- | ------------------------------- |
| 切换方式 | Transition 层统一管理，黑场/白场淡入淡出 0.4s |
| 传送   | 同层复用（神像传送、任务跳转）                 |
| 加载画面 | 仅首关做，其余秒切                       |

## 二、玩法层

### 2.1 任务系统 · NPC 头顶标记

标记渲染沿用交互提示规则（不参与 Y-sort，z\_index=100，逐 NPC 独立显隐），位置在名牌上方，带轻微上下浮动动画。

| 状态          | 图形    | 主线           | 支线           | 心契           |
| ----------- | ----- | ------------ | ------------ | ------------ |
| 待接取         | 问号 ？  | `#FFA640` 橘黄 | `#6FC9FF` 淡蓝 | `#FF8FC8` 粉红 |
| 已接取·可交付/待交互 | 感叹号 ！ | 同上           | 同上           | 同上           |
| 进行中·无需交互    | 不显示   | —            | —            | —            |

- 同一 NPC 同时有多任务时，按 **主线 > 心契 > 支线** 显示最高优先级一个，交互后逐个弹出
- 标记颜色与任务面板中的任务条目色一致，建立色彩记忆
- 标记来源：NPC 关联的 quest\_id 列表，由 GameState 任务进度决定显示哪种标记

**交叉引用**：T1.5 交互系统 R1\~R4（Area2D r=60、距离仲裁、信号 `interact_requested`）。

### 2.2 神像机制（暂定名「星痕神像」）

| 行为 | 规格                                                                      | 备注                                         |
| -- | ----------------------------------------------------------------------- | ------------------------------------------ |
| 恢复 | 进入光环范围（半径 96px）**自动恢复全部角色状态**（HP/星缘/状态重置），飘字+光效+音效反馈，不弹 UI            | 星髓无耐久/冷却概念（§2.5），恢复项不含星髓 |
| 点亮 | 首次靠近提示「按 E 点亮」→ 短演出（光柱+粒子）→ 解锁该神像传送点 + 所属地图区块由暗转亮 + 首亮奖励（建议星砂×100，数值待定） | 剧情文案策划负责正式命名                               |
| 传送 | 世界大地图点击已点亮神像 → 确认框 → Transition 淡出淡入 → 落点神像旁出生点                         | 同层复用                                       |
| 存档 | 已点亮神像旁按 E → 神像菜单：**存档 / 恢复状态 / 查看此区域提示**                                | 手动档，独立于自动档                                 |

### 2.3 地图系统

#### 箱庭图（M 键 · 当前场景）

| 项        | 规格                                                         |
| -------- | ---------------------------------------------------------- |
| 呈现       | 半透明暗底 + **仅描边**的当前箱庭轮廓（可行走区域线框，由场景边界+兴趣点表实时生成）             |
| 标注       | 主角当前位置（体系色箭头）、重要 NPC 点位（金色菱形）、神像点位（已点亮亮色/未点亮灰）、场景出口        |
| 交互       | 鼠标滚轮**向下** → 平滑缩放过渡进世界大地图；滚轮向上 → 平滑缩放过渡进箱庭地图。ESC：关闭全部地图面板。 |
| NPC 标注范围 | **仅任务相关 NPC**（非全部可交互 NPC），减少噪点                             |

| 项    | 规格                                      |

### 2.4 存档系统

| 项      | 规格                                                                      |
| ------ | ----------------------------------------------------------------------- |
| 手动档    | 神像触发，覆盖式 1 槽 + 3 槽回滚防坏档（v0.2 拍板默认值）                                     |
| 自动档    | 进场景 / 任务关闭 / 点亮神像时静默写入，独立槽                                              |
| 主菜单入口  | 读档入口；坏档自动回退上一槽                                                          |
| 存档内容   | GameState 全部 flag、编队、Inventory（道具/星髓仓库/图鉴）/星砂/星缘令、任务进度、神像与地图解锁、抽卡保底计数、角色养成数据、设置项（设置独立于进度档） |
| MVP 范围 | GameState 序列化 + 单自动槽 + 神像手动槽                                            |

### 2.5 角色星髓系统

| 项    | 规格                         |
| ---- | -------------------------- |
| 装备槽  | 每角色固定 **6 槽**，槽位网格 2×3     |
| 体系判定 | 星髓仅提供2件套数值属性+3件套效果属性，与体系无关 |
| 持有归属 | 数据仓库=Inventory.starmarrow（逐枚实例，含装备者记录）；**背包 UI 无星髓 Tab**，查看/装备/养成在角色面板→星髓面板（规则见 docs/系统规则/星髓系统.md） |
| 充能词条 | 消费点=战斗充能条积累效率（docs/系统规则/战斗系统.md §3） |

### 2.6 常驻 HUD

### 2.7 手感细则（全项目通用）

## 四、数据层

### 4.1 EventBus 信号扩展

T0.4 已注册 8 条核心信号，新增以下系统信号：

| 信号                                                | 参数               | 触发源          | 订阅方           |
| ------------------------------------------------- | ---------------- | ------------ | ------------- |
| `shrine_lit(shrine_id)`                           | String           | 系统程序（点亮神像）   | 存档系统、地图系统、HUD |
| `shrine_entered_radius(shrine_id)`                | String           | 系统程序（光环触发）   | 恢复系统、音效       |
| `map_region_unlocked(region_id)`                  | String           | 剧情事件 / 神像点亮  | 世界大地图、存档系统    |
| `party_changed(party_list)`                       | Array            | Party.gd     | 角色列表 UI、存档系统  |
| `starmarrow_changed(character_id, before, after)` | String, int, int | 星髓装备/卸下      | 角色详情、存档系统     |
| `ui_open(panel_name)` / `ui_closed(panel_name)`   | String           | Transition 层 | 暂停管理器、音效      |

**规则**：新增信号必须先注册到 EventBus.gd 再使用，禁止散写 emit。

### 4.2 存档序列化清单

| 类             | 字段                                      | 说明              |
| ------------- | --------------------------------------- | --------------- |
| GameState     | 全部 flag + star\_sand / starlink\_tokens | 货币与任务进度、神像解锁、地图解锁 |
| Party.gd      | current\_party / companion              | 编队与同行           |
| Inventory     | items / starmarrow / cg\_collection      | 道具、星髓仓库（逐枚实例，背包 UI 不展示星髓）与图鉴（**货币 star\_sand/starlink\_tokens 在 GameState**，存档时一并序列化） |
| GachaPool     | pity\_counter                           | 保底计数            |
| CharacterData | 已获角色的等级/经验/星缘/星髓槽                       | 养成数据            |
| ShrineSystem  | lit\_shrines                            | 点亮神像列表          |
| MapSystem     | unlocked\_regions                       | 解锁区块列表          |
| Settings      | audio / display / input                 | 独立档             |

### 4.3 CSV 扩展预留

现有 CSV：characters / skills / enemies / stellium / summon\_pool / quests / dialogues。预留扩展列：

- characters.csv：`starmarrow_slots`（固定 6，可省略）、`sprite_idle_8dir` / `sprite_walk_8dir`（美术资源引用）
- quests.csv：`quest_type`（main / side / bond）、`priority`（标记优先级）、`mark_color`（覆盖默认色彩）

### 4.4 系统接口清单

以下为跨系统调用的对外函数签名，供 T2.3\~T2.4 卡实现时对齐。

| 系统           | 函数                                           | 签名                                                                            | 说明                              |
| ------------ | -------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------- |
| Transition 层 | `transition_scene`                           | `transition_scene(from_path: String, to_path: String, duration: float = 0.4)` | 同层复用，淡入淡出                       |
| Transition 层 | `transition_portal`                          | `transition_portal(target_id: String, duration: float = 0.4)`                 | 传送（神像/任务跳转），target\_id 指向目标场景节点 |
| Transition 层 | `transition_fade_out` / `transition_fade_in` | 无参，duration 默认 0.4                                                            | 独立淡入淡出（用于 UI 面板开关效果辅助）          |
| 存档系统         | `save_game`                                  | `save_game(slot_id: String, is_auto: bool = false) -> bool`                   | 写入存档，is\_auto=true 时走自动档        |
| 存档系统         | `load_game`                                  | `load_game(slot_id: String) -> Dictionary`                                    | 读取存档，坏档返回空字典 + 日志               |
| 存档系统         | `rollback_auto`                              | `rollback_auto() -> bool`                                                     | 坏档时回退自动档上一槽                     |
| 存档系统         | `has_save`                                   | `has_save(slot_id: String) -> bool`                                           | 检查存档是否存在                        |
| 地图系统         | `unlock_region`                              | `unlock_region(region_id: String) -> void`                                    | 解锁区块（神像点亮 / 剧情事件触发）             |
| 地图系统         | `is_region_unlocked`                         | `is_region_unlocked(region_id: String) -> bool`                               | 查询区块解锁状态                        |
| 地图系统         | `get_region_by_shrine`                       | `get_region_by_shrine(shrine_id: String) -> String`                           | 反查神像所属区块                        |
| 暂停管理器        | `pause_game`                                 | `pause_game(reason: String) -> void`                                          | 打开 UI/对话时暂停，reason 用于调试         |
| 暂停管理器        | `resume_game`                                | `resume_game(reason: String) -> void`                                         | 关闭 UI/对话时恢复                     |
| 暂停管理器        | `is_paused`                                  | `is_paused() -> bool`                                                         | 查询暂停状态                          |

**实现规则**：Transition 层、存档系统、地图系统、暂停管理器均为 Autoload 单例；EventBus 信号为唯一跨系统通知渠道；函数返回值类型与参数命名统一 Godot 4.7 风格。
