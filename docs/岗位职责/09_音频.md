## 0. 岗位一句话定位

对**音频规范与资源接入**负责：MVP 阶段定义 BGM/音效命名与规格规范，并在 T7.3 用 AI 生成 1 段 BGM 接入替换静音占位，验证播放正常。MVP 音频工作量轻，重点是规范先行、接口可换。

## 3. 核心职责细则

1. **命名与规格规范**：
   - BGM：`assets/audio/bgm_<scene>.ogg`（44.1kHz/16bit，建议 60\~120s 循环段）
   - 音效：`assets/audio/sfx_<event>.ogg`（1\~3s）
2. **AI 音乐生成**：Suno 等工具 → 输出 → 转 OGG；合规使用自有生成资源，规避版权风险；工具与风格词记录在 `docs/美术资源接入清单.md`（与美术共用一份清单）。
3. **接入验证（T7.3）**：在营地场景挂 AudioStreamPlayer 播放 `bgm_camp.ogg`，确认音量/循环正常、无爆音；播放走 ArtProvider.get\_bgm，不直接引用路径。
4. **接口预留**：音效在 MVP 只有占位接口（静音），后续补 `sfx_<event>.ogg` 即可，不改代码。

## 4. 与其他岗位的协作接口

- **交付给系统程序**：音频命名规范 + T7.3 的 BGM 文件与播放验证结果。
- **从系统程序接收**：ArtProvider 音频接口签名、营地场景可播放确认。
- **与美术配合**：共用 `docs/美术资源接入清单.md`，音乐资源路径登记在清单音频部分。

## 5. 质量标准与验收自查

- [ ] 音频命名 100% 符合 §5.2 规范
- [ ] bgm\_camp.ogg 为 44.1kHz/16bit OGG，时长/循环符合规范
- [ ] 营地场景 BGM 播放正常（音量/循环无异常），走 ArtProvider 接口
- [ ] AI 工具与风格词已记入接入清单

## 6. 交接班表

- **作用**：让系统程序知道音频规范与接入进展；接入清单是 T7.3 验收证据的一部分。
- **存放**：`D:\Dev\HuiJieXingHen\docs\handover\音频_交接班表.md`
- **填写时机**：规范发布后；T7.3 每个音频接入实例完成后。
- **模板**：

## 7. 开工 / 收工 SOP

2. 收工：验证播放 → 追加交接行 → 通知系统程序。
