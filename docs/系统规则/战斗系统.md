## 1. 战斗形式与场景表现

| 项 | 规则 |
| --- | --- |
| 战斗形式 | **3 人小队回合制**（Q 版战场，与《初期设定》一致） |
| 战场背景 | **取当前地图地板**：复用触发战斗时所在地图的 TileMapLayer 地板层 |
| 隐藏项 | 进入战斗时隐藏：常规跑图 UI（HUD/交互提示等）、建筑物、装饰物、NPC |

| 出入口 | 进入/退出战斗经 Transition 层淡入淡出（T3.7 地图触发 `battle_started` 接入） |

## 2. 跑速条制（行动顺序核心机制）

1. **速度条**：屏幕右侧竖向显示，上限 **100**；条上显示我方与敌人的头像标记。
2. **轮次推进**：回合开始时，所有角色与敌人置于速度条 **0** 的位置；随后按**各自速度**沿条前推，**最先到达 100 者出手**；出手后该单位回到速度条 0，继续参与前推。
3. **轮次边界**：当一轮内所有参战单位均已出手过，本回合结束，全员归零开始下一回合（轮次边界的细则见 §8 C8）。
4. **速度来源**：角色/敌人属性均有**初始速度**；战斗中角色速度 = 面板基础速度 + 星髓加成（§4）。
5. 头像标记随单位在条上前推实时移动，出手瞬间高亮。

## 3. 技能系统

| 项 | 规则 |
| --- | --- |
| 技能种类 | 角色与敌人均有 **小技能** 与 **大招** 两种攻击方式 |
| 小技能 | **每个行动轮次均可使用**，无消耗 |
| 大招 | 需**充能条达到 100** 解锁；释放一次后**充能条重置为 0** |
| 图标状态 | 充能未满：大招图标**灰色**；充能满：**亮色闪光**（提示可释放） |
| 充能积累 | 充能条 0→100 的积累途径**待定**（§8 C4，转数值策划定义；建议：小技能命中+X、受击+Y 一类） |
| 机制预留 | 部分角色可设定为**大招无需充能**——数据层预留机制字段（如 skills.csv 角色机制标记），MVP 三名觉醒者不启用，仅保证后续设计角色时改机制与数值即可，不改战斗框架代码 |

> 与 T2.1 数值口径的关系：原 `energy_cost=1/3`（能量点制）口径随本规则**作废重定义**（见 §8 C2），power 倍率口径不变。

## 4. 属性与星髓加成

1. 角色与敌人的战斗属性均有**初始值**（hp/atk/def/spd 等，来自 characters.csv / enemies.csv）。
2. 战斗时**角色属性叠加星髓加成**（装备属性并入面板，进战斗带入）：
   - **速度**：星髓速度词条 → 速度条前推速率加成（§2）；
   - **充能**：星髓充能词条 → 充能条积累效率加成（§3；此即星髓系统文档 §8 C4 的消费点，本规则落地后该项待定解除）；
   - 攻击/防御/血量/暴击/爆伤：常规并入伤害与生存属性。
3. 星髓套装效果（2件套数值/3件套条件增伤）战斗结算时生效（接口见星髓系统文档 §7.1）。
4. 敌人无星髓，仅初始属性 + AI 机制。

## 5. 战斗 UI 布局

| 区域 | 内容 |
| --- | --- |
| 屏幕右下角 | **三角色头像**横排，每个头像旁含**血条**；当前激活回合角色的头像高亮 |
| 屏幕右侧（竖向） | **速度条**（上限 100），条上实时显示我方与敌人头像位置（§2） |
| 指令区 | 当前激活角色的可用指令：小技能 / 大招（充能未满灰显、满则亮色闪光）/（预留：道具等扩展位） |
| 立绘位 | 屏幕右下角显示**当前回合激活角色的立绘**（§6 演出联动） |

- 战斗 UI 为独立 CanvasLayer，不参与地图 Y-sort；跑图 HUD 在战斗期间隐藏，战斗结束恢复。

## 6. 战斗演出

| 时机 | 表现 |
| --- | --- |
| 战场常态 | 角色 **Q 版小人**在屏幕上列队放置（与敌人分列） |
| 角色回合激活 | 屏幕右下角显示**当前回合角色的立绘**（高清立绘，Q 版战场 + 高精度角色的反差，与《初期设定》一致） |
| 释放小技能 | 右下角立绘**更换为技能释放动态立绘**（播毕切回常态立绘） |
| 释放大招 | **全屏显示技能释放 CG**（占位阶段：色块动画+技能名大字，正式 CG 由美术后期接入，走 ArtProvider.get_skill_fx） |

- 演出期间战斗逻辑等待；支持跳过（沿用 T3.6 既有跳过设计）。
