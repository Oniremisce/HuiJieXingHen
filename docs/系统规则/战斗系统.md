## 2. 跑速条制（行动顺序核心机制）

1. **速度条**：屏幕右侧竖向显示，上限 **100**；条上显示我方与敌人的头像标记。
2. **轮次推进**：回合开始时，所有角色与敌人置于速度条 **0** 的位置；随后按**各自速度**沿条前推，**最先到达 100 者出手**；出手后该单位回到速度条 0，继续参与前推。战斗演出时不得停留在等待跑条时间，后台计算跑条结果瞬间推进到敌我出手回合，出手回合时，跑条暂停，出手后循环。
3. **轮次边界（已裁定）**：每单位**每轮限出手一次**——出手后归 0 不再前推；当一轮内所有参战单位均已出手过，本回合结束，全员归零开始下一回合。多个单位**同时到达 100**：spd 高者优先、同值我方优先、再同值按编队序。高速单位一轮内连续多动（CTB）留 MVP+ 扩展。
4. **速度来源**：角色/敌人属性均有**初始速度**；战斗中角色速度 = 面板基础速度 + 星髓加成（§5；星髓速度词条为固定值）。
5. 头像标记随单位在条上前推实时移动，出手瞬间高亮，其他头像标记暂停跑条。

## 3. 技能系统

| 项    | 规则                                                                                          |
| ---- | ------------------------------------------------------------------------------------------- |
| 技能种类 | 角色与敌人均有 **小技能** 与 **大招** 两种攻击方式                                                             |
| 小技能  | **每个行动轮次均可使用**，无消耗                                                                          |
| 大招   | 需**充能条充满（达到充能上限，MVP 默认 100）**解锁；释放一次后**充能条重置为 0**                                                        |
| 图标状态 | 充能未满：大招图标**灰色**；充能满：**亮色闪光**（提示可释放）                                                         |
| 充能积累 | 充能条上限由角色属性定义（MVP 默认 100，BattleUnit.charge\_max，后续角色机制可覆写）；积累途径与初版数值（已裁定）：**小技能命中 +20 / 受到伤害 +15 / 自身回合激活开始 +10**；星髓充能词条按百分比加成积累量（平衡微调归数值策划，不再阻塞） |
| 机制预留 | 部分角色可设定为**大招无需充能**——代码层预留机制标记 `charge_free: bool`（默认 false，MVP 三名觉醒者恒 false）；改机制与数值即可，不改战斗框架代码 |

> 与 T2.1 数值口径的关系：原 `energy_cost=1/3`（能量点制）口径**已作废**——skills.csv 删除 energy\_cost 列、SkillData 删除 energy\_cost 字段（T2.8 执行，跨岗知会系统程序）；「无需充能」用代码层 charge\_free 标记预留（原 C2/C7，已裁定）。

## 4. 角色体系效果（共振 / 汇流 / 混元）

> 三态**判定逻辑**沿用《队伍系统》规则 §5（三系齐→混元、全员同系→共振、两系混编→汇流，互斥，进战斗时由 `Party.team_systems()` 判定，T2.2 已交付）；三态**效果内容**以本章为准——原被动数值加成（atk+10% 等）已作废（原 C15，已裁定，见 §9）。

### 4.1 共振（全员同系）

| 项 | 规则 |
| --- | --- |
| 触发条件 | 战斗中**三名角色都释放过大招**后自动触发（各释放 ≥1 次即计入；触发后计数重置，可循环再触发；角色死亡其已释放次数保留） |
| 合击技 | **三人合击技**：不看跑条，触发瞬间插入释放（不占任何角色行动轮次，不等待速度条；与 §2.2 后台跑条/演出暂停规则衔接）；合击触发**不消耗、不改变**三人速度条位置与充能 |
| 合击演出 | 播放**合击 CG**（全屏；占位阶段=色块动画+合击技名大字，正式 CG 走 ArtProvider.get_skill_fx） |
| 目标 | **全体敌人** |
| 伤害 | **三人攻击力之和 × 100%**（已死亡角色不计入求和；合击倍率 100% 已定，平衡微调归数值策划） |
| 暴击 | **可暴击**：合击暴击率 = **三人暴击率之和 ÷ 300%**（例：三人各 20% → 20%）；合击暴击伤害 = **固定 300%**（固定值，不受爆伤词条/星髓爆伤加成影响） |

### 4.2 汇流（两系混编）

| 项 | 规则 |
| --- | --- |
| 单体效果 | 角色**单独释放大招后**，该角色大招充能条**自动充能 30%**（释放后充能条不归 0，而置为充能上限的 30%；上限口径见 §3） |
| 全体效果 | **三人（全队）都释放过大招后**，全体我方**拉条 30%**（速度条位置 +30）；已裁定细则：拉条后位置 ≥100 者立即按跑条规则触发出手（多个达标按 spd 高者优先、我方优先）；拉条对**本轮已出手单位无效**（位置不动）；拉条瞬间如有演出进行，演出结束后结算 |
| 计数口径 | 「三人都释放过大招」的计数窗口与共振同规则（各 ≥1 次、触发后重置、死亡保留） |

### 4.3 混元（三系齐全）

| 项 | 规则 |
| --- | --- |
| 效果 | 全队角色**全属性增幅 30%**，进战斗时生效、持续整场 |
| 属性范围 | 「全属性」= 四维 hp/atk/def/spd（速度条前推效率随 spd 生效）；**不含**暴击/爆伤/充能效率（防止乘区失控，已裁定） |

### 4.4 生效时点与叠加

1. 体系判定进战斗时确定，战斗中编队不变则体系效果不变。
2. 混元全属性增幅在星髓属性**并入之后**按百分比放大（先加算后乘算）。
3. 合击伤害走**常规伤害管线**（含目标防御减免、星髓 3 件套条件增伤等乘区生效），仅暴击率/暴伤为专用值（已裁定）。
4. 敌人无体系效果。

## 5. 属性与星髓加成

1. 角色与敌人的战斗属性均有**初始值**（hp/atk/def/spd 等，来自 characters.csv / enemies.csv）。
2. 战斗时**角色属性叠加星髓加成**（装备属性并入面板，进战斗带入）：
   - **速度**：星髓速度词条 → 速度条前推速率加成（§2）；
   - **充能**：星髓充能词条 → 充能条积累效率加成（§3；星髓系统文档原 C4 已裁定解决）；
   - 攻击/防御/血量/暴击/爆伤：常规并入伤害与生存属性。
3. 星髓套装效果（2件套数值/3件套条件增伤）战斗结算时生效（接口见星髓系统文档 §7.1）。
4. 敌人无星髓，仅初始属性 + AI 机制。
