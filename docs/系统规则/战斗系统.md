## 2. 跑速条制（行动顺序核心机制）

1. **速度条**：屏幕**左侧竖向细长条**（进度条样式），**高度 = 屏幕竖向高度 × 1/3**，上限 **100**；**跑条方向自上而下**（顶端=0、底端=100）；我方与敌人的**圆形小头像**置于条上随位置实时移动（**头像直径 = 速度条宽度 × 2**）。
2. **轮次推进**：回合开始时，所有角色与敌人置于速度条 **0** 的位置；随后按**各自速度**沿条前推，**最先到达 100 者出手**；出手后该单位回到速度条 0，继续参与前推。
3. **跑条动画**：非出手单位的跑条过程必须以**动画形式呈现**（禁止瞬间切换到下一出手单位）。视觉基准：按**当前出战单位的平均跑条速度**换算，**完整跑完全条 = 1 秒**（表现参数，后续可优化调整）；各头像按自身速度呈现相对快慢，实际出手先后按后台结算判定。出手回合时跑条动画暂停，出手后恢复循环。
4. **轮次边界**：每单位**每轮限出手一次**——出手后归 0 不再前推；当一轮内所有参战单位均已出手过，本回合结束，全员归零开始下一回合。多个单位**同时到达 100**：spd 高者优先、同值我方优先、再同值按编队序。高速单位一轮内连续多动（CTB）留 MVP+ 扩展。
5. **速度来源**：角色/敌人属性均有**初始速度**；战斗中角色速度 = 面板基础速度 + 星髓加成（§5；星髓速度词条为固定值）。
6. 头像标记出手瞬间高亮，其他头像标记暂停跑条。

## 3. 技能系统

| 项    | 规则                                                                                          |
| ---- | ------------------------------------------------------------------------------------------- |
| 技能种类 | 角色与敌人均有 **小技能** 与 **大招** 两种攻击方式                                                             |
| 小技能  | **每个行动轮次均可使用**，无消耗                                                                          |
| 大招   | 需**充能条充满（达到充能上限，MVP 默认 100）**解锁；释放一次后**充能条重置为 0**                                                        |
| 图标状态 | 充能未满：大招图标**灰色**；充能满：**亮色闪光**（提示可释放）                                                         |
| 充能积累 | 充能条上限由角色属性定义（MVP 默认 100，BattleUnit.charge\_max，后续角色机制可覆写）；积累途径与初版数值：**小技能命中 +20 / 受到伤害 +15 / 自身回合激活开始 +10**；星髓充能词条按百分比加成积累量（平衡微调归数值策划） |
| 机制预留 | 部分角色可设定为**大招无需充能**——代码层预留机制标记 `charge_free: bool`（默认 false，MVP 三名觉醒者恒 false）；改机制与数值即可，不改战斗框架代码 |

### 3.1 技能目标与效果（target_side / target_scope / effect）

- 技能设定口径见《角色系统》§3；战斗侧按三字段驱动：**target_side**（enemy/ally）、**target_scope**（single/column/all）、**effect**（damage/heal/shield/amp）。
- **目标阵营**：enemy=攻击敌人（缺省）；**ally=对友方释放**（治疗/护盾/增伤）——友方技能同走充能与出手规则，目标选择见 §8.2。
- **范围枚举**：single（单体）/ column（整列，**仅敌方**，上限 3，列=§9 前列/后列）/ all（全体，敌上限 6、友=全队）；ally 侧仅用 single/all。组合范围扩展由「目标集合选取器」接口预留，新增范围不改战斗框架。
- **效果枚举与结算**：

| effect | 效果 | 结算规则 |
| --- | --- | --- |
| damage | 伤害（缺省） | 常规伤害管线（§4.4 乘区，T3.4 交付） |
| heal | 治疗 | 目标恢复 HP = 施法者 atk × power，上限不超过目标最大 HP |
| shield | 护盾 | 目标获得护盾值 = 施法者 atk × power；**先于 HP 吸收伤害**，耗尽即消失、不随时间衰减 |
| amp | 增伤 | 目标**下次攻击**伤害 +power 百分点；每目标独立持有、出手结算时消费并移除（乘区接入 §4.4 伤害管线） |

- 「列」的口径见 §9 对阵阵型：敌方阵地第三列=前列、第四列=后列。

## 4. 角色体系效果（共振 / 汇流 / 混元）

> 三态**判定逻辑**沿用《队伍系统》规则 §5（三系齐→混元、全员同系→共振、两系混编→汇流，互斥，进战斗时由 `Party.team_systems()` 判定）；三态**效果内容**以本章为准。

### 4.1 共振（全员同系）

| 项 | 规则 |
| --- | --- |
| 触发条件 | 战斗中**三名角色都释放过大招**后自动触发（各释放 ≥1 次即计入；触发后计数重置，可循环再触发；角色死亡其已释放次数保留） |
| 合击技 | **三人合击技**：不看跑条，触发瞬间插入释放（不占任何角色行动轮次，不等待速度条；与 §2.3 跑条暂停规则衔接）；合击触发**不消耗、不改变**三人速度条位置与充能 |
| 合击演出 | 播放**合击 CG**（全屏；占位阶段=色块动画+合击技名大字，正式 CG 走 ArtProvider.get_skill_fx） |
| 目标 | **全体敌人** |
| 伤害 | **三人攻击力之和 × 100%**（已死亡角色不计入求和；合击倍率 100% 已定，平衡微调归数值策划） |
| 暴击 | **可暴击**：合击暴击率 = **三人暴击率之和 ÷ 300%**（例：三人各 20% → 20%）；合击暴击伤害 = **固定 300%**（固定值，不受爆伤词条/星髓爆伤加成影响） |

### 4.2 汇流（两系混编）

| 项 | 规则 |
| --- | --- |
| 单体效果 | 角色**单独释放大招后**，该角色大招充能条**自动充能 30%**（释放后充能条不归 0，而置为充能上限的 30%；上限口径见 §3） |
| 全体效果 | **三人（全队）都释放过大招后**，全体我方**拉条 30%**（速度条位置 +30）；细则：拉条后位置 ≥100 者立即按跑条规则触发出手（多个达标按 spd 高者优先、我方优先）；拉条对**本轮已出手单位无效**（位置不动）；拉条瞬间如有演出进行，演出结束后结算 |
| 计数口径 | 「三人都释放过大招」的计数窗口与共振同规则（各 ≥1 次、触发后重置、死亡保留）；**拉条提前出手的大招不计入计数窗口**（防止拉条与计数窗口连锁，触发后重新攒窗） |

### 4.3 混元（三系齐全）

| 项 | 规则 |
| --- | --- |
| 效果 | 全队角色**全属性增幅 30%**，进战斗时生效、持续整场 |
| 属性范围 | 「全属性」= 四维 hp/atk/def/spd（速度条前推效率随 spd 生效）；**不含**暴击/爆伤/充能效率（防止乘区失控）；增幅取整=**向下取整（int 截断）**，进战斗属性并入时一次完成（乘区内无二次取整） |

### 4.4 生效时点与叠加

1. 体系判定进战斗时确定，战斗中编队不变则体系效果不变。
2. 混元全属性增幅在星髓属性**并入之后**按百分比放大（先加算后乘算）。
3. 合击伤害走**常规伤害管线**（含目标防御减免、星髓 3 件套条件增伤等乘区生效），仅暴击率/暴伤为专用值；条件增伤按各存活角色星髓满足条件者求和（每个敌人按其结算时 HP 比例独立判定）。
4. 敌人无体系效果。
5. 编组不足 3 人时体系效果不生效（MVP 三人小队前提）。

## 5. 属性与星髓加成

1. 角色与敌人的战斗属性均有**初始值**（hp/atk/def/spd 等，来自 characters.csv / enemies.csv）。
2. 战斗时**角色属性叠加星髓加成**（装备属性并入面板，进战斗带入）：
   - **速度**：星髓速度词条 → 速度条前推速率加成（§2）；
   - **充能**：星髓充能词条 → 充能条积累效率加成（§3）；
   - 攻击/防御/血量/暴击/爆伤：常规并入伤害与生存属性。
3. 星髓套装效果（2件套数值/3件套条件增伤）战斗结算时生效（接口见星髓系统文档 §7.1）。
4. 敌人无星髓，仅初始属性 + AI 机制。

### 5.1 角色等级、经验与升级

| 项 | 规则 |
| --- | --- |
| 等级与经验 | 角色携带**等级 Lv（初始 1）**与**经验 exp**，为**存档字段**（CharacterData 扩展 level/exp，不入 characters.csv 静态表） |
| 经验获取 | 两途径：① **战斗**——战斗胜利结算按战斗信息发放经验（battle_finished 结算链扩展，随星砂一并入账）；② **喂升级材料**——角色面板喂食升级材料获得经验（面板设定见《角色系统》§2.1） |
| 升级 | 经验达当前等级上限即升级、溢出结转；升级提升基础四维（成长值=数值策划定值，随等级生效于战斗属性） |
| 战斗内锁定 | 战斗中不升级、不发经验，战后统一结算 |
| 数值口径 | 经验曲线、升级四维成长值、材料经验值归**数值策划**定值（进 CSV/常量，禁止硬编码） |

## 6. 战斗 UI 布局

| 区域       | 内容                                              |
| -------- | ----------------------------------------------- |
| 屏幕右上角    | **自动/手动战斗切换开关**（§8.1；MVP 默认自动，战斗中可随时切换）         |
| 屏幕左侧（竖向） | **速度条**：竖向细长条（上限 100），**高度 = 屏幕竖向高度 × 1/3**，跑条**自上而下**（§2），条上圆形小头像跑条（直径=条宽×2） |
| 屏幕左下角    | **角色信息板块 ×3**——**必显项**：全体参战角色横排 3 个板块（**互不重叠**）。单板块结构：左端**角色头像**；头像右侧自上而下=**角色名**（血条上方）→ **血条**（含「当前HP/最大HP」数字）→ **buff 状态图标行**（当前 buff 有几个显示几个、总宽不超过血条）；头像下方=**等级（Lv.xx）**；当前出手角色板块高亮；战斗全程常显（含结算/重试态） |
| 屏幕右下角    | **当前激活角色立绘**（§7）；不放置参战头像/血条行 |
| 指令按钮区    | 立绘下方并排**两按钮：小技能 / 大招**（大招充能未满灰显、满则亮色闪光）；手动模式激活回合显示，快捷键 **E=小技能、Q=大招**（§8.1）；（预留：道具等扩展位） |
| 战场单位头顶   | 我方角色=**体系图标+血条常显**；敌方=**红色血条常显**（平时无箭头；目标选择箭头仅 §8.2 选择状态显示） |
| 禁止项      | 战斗界面**不得出现**：屏幕左下角横向一排方框色块占位、屏幕下方居中的怪物色块占位与怪物名称（旧战场占位渲染移除，战场单位表现由 §9 阵型承载）、**棋盘格渲染**（§9 阵型格仅为模型站位逻辑位置，UI 不显示棋盘格） |

- 战斗 UI 为独立 CanvasLayer，不参与地图 Y-sort；跑图 HUD 在战斗期间隐藏，战斗结束恢复。
- 战斗内按键作用于战斗 UI（战斗状态优先于跑图绑定；E 在战斗内=小技能/目标确认，不触发跑图交互）。

## 8. 战斗模式与目标选择

### 8.1 自动 / 手动模式

| 项 | 规则 |
| --- | --- |
| 切换 | **屏幕右上角开关**，战斗中随时切换，立即生效 |
| 自动 | 我方出手由 AI 自动选定技能与目标（与敌方 ai_pattern 同级逻辑），无目标选择 UI |
| 手动 | **轮到我方角色出手**（战斗待机状态）时，右下角立绘下方显示**小技能 / 大招两按钮**；快捷键 **E=小技能、Q=大招**（大招需充能满或 charge_free，未满按 Q 无效并有提示）；选定技能后进入目标选择状态（§8.2）；等待玩家操作期间跑条动画暂停（§2.3） |
| 默认 | MVP 默认**自动** |

### 8.2 目标选择（选择目标状态）

释放技能后进入**选择目标状态**：目标单位头顶显示**指示箭头**——敌方技能为**向下箭头**指向敌人（**箭头位于敌方头顶血条的中间上方、不与血条重叠；敌方平时仅显示血条无箭头，仅选择状态显示箭头，确认/取消后即消失**），**友方技能为向上箭头指向我方队友**；按**移动键（方向键）**在可选目标间切换箭头，确认后释放。箭头数量与可选规则按技能目标阵营与范围（§3.1）：

| 技能类型 | 箭头表现 | 选择规则 |
| --- | --- | --- |
| 敌方单体（enemy+single） | **1 个向下箭头**指向单个敌人 | **任意敌人**可选，移动键切换 |
| 敌方整列（enemy+column） | **3 个向下箭头**指向整列敌人（列内不足 3 人时指向实际在场者） | 仅在**前列 / 后列**之间切换 |
| 敌方全体（enemy+all） | **6 个向下箭头**指向全部敌人 | **无需选择**，确认即释放 |
| 友方单体（ally+single，治疗/护盾） | **1 个向上箭头**指向单个队友 | 队友间移动键切换（含满血目标——治疗溢出无效，护盾可叠加刷新） |
| 友方全体（ally+all，增伤） | **全队向上箭头** | **无需选择**，确认即释放 |

- 确认键：目标选择状态下 **E / 空格 = 确认释放**（E 在此状态下为确认语义，不再触发新技能）；Esc 取消回指令按钮。
- 自动模式下无箭头 UI，AI 直接按范围与效果结算（友方技能 AI 规则：heal 优先最低血量队友、shield 优先当前承伤位/T3.11 占位逻辑）。

### 8.3 伤害与效果飘字

- **无论自动/手动**，技能生效时受影响单位头顶显示**飘字**：伤害（敌我通用，向上飘动渐隐）、治疗（恢复量，绿色占位）、护盾（获得盾值，蓝色占位）；占位=色块字 Label，正式样式归美术 T7.3。暴击可加视觉区分（MVP 可选）。

## 9. 对阵阵型（战场布置）

进入战斗后，双方模型摆出**对阵阵型**：

| 项 | 规则 |
| --- | --- |
| 阵型格 | **4 列 × 3 行**格子区域，整体呈矩形**斜向摆放**：区域右边缘向上斜 45°、左边缘向下斜 45°；**格子仅为模型站位的逻辑位置，战斗 UI 不绘制棋盘格（格线/格底一律不显示）** |
| 我方阵地 | **第一列（1×3）**=我方 3 个角色模型，位于**屏幕中间左下角**同排排列 |
| 分界列 | **第二列**=空白分界线（不站人） |
| 敌方阵地 | **第三、四列 ×3 行**=敌方阵地，位于**屏幕中间右上角**排列；敌方**最多 6 人、最少 1 人** |
| 站位生成 | 我方按实际出战人数站位、敌方按本场战斗信息生成数量；阵地允许空位 |
