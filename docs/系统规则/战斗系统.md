## 2. 跑速条制（行动顺序核心机制）

1. **速度条**：屏幕右侧竖向显示，上限 **100**；条上显示我方与敌人的头像标记。
2. **轮次推进**：回合开始时，所有角色与敌人置于速度条 **0** 的位置；随后按**各自速度**沿条前推，**最先到达 100 者出手**；出手后该单位回到速度条 0，继续参与前推。战斗演出时不得停留在等待跑条时间，后台计算跑条结果瞬间推进到敌我出手回合，出手回合时，跑条暂停，出手后循环。
3. **轮次边界**：当一轮内所有参战单位均已出手过，本回合结束，全员归零开始下一回合（轮次边界的细则见 §9 C8）。
4. **速度来源**：角色/敌人属性均有**初始速度**；战斗中角色速度 = 面板基础速度 + 星髓加成（§4）。
5. 头像标记随单位在条上前推实时移动，出手瞬间高亮，其他头像标记暂停跑条。

## 3. 技能系统

| 项    | 规则                                                                                          |
| ---- | ------------------------------------------------------------------------------------------- |
| 技能种类 | 角色与敌人均有 **小技能** 与 **大招** 两种攻击方式                                                             |
| 小技能  | **每个行动轮次均可使用**，无消耗                                                                          |
| 大招   | 需**充能条达到 100** 解锁；释放一次后**充能条重置为 0**                                                         |
| 图标状态 | 充能未满：大招图标**灰色**；充能满：**亮色闪光**（提示可释放）                                                         |
| 充能积累 | 充能条上限由角色属性定义，释放小技能、受击、其他角色技能机制涨充能（§9 C4，转数值策划定义；上限属性化与「充满解锁」表述的统一见 §9 C13） |
| 机制预留 | 部分角色可设定为**大招无需充能**——数据层预留机制字段（如 skills.csv 角色机制标记），MVP 三名觉醒者不启用，仅保证后续设计角色时改机制与数值即可，不改战斗框架代码 |

> 与 T2.1 数值口径的关系：原 `energy_cost=1/3`（能量点制）口径随本规则**作废重定义**（见 §9 C2），power 倍率口径不变。

## 4. 角色体系效果（共振 / 汇流 / 混元）

> 三态**判定逻辑**沿用《队伍系统》规则 §5（三系齐→混元、全员同系→共振、两系混编→汇流，互斥，进战斗时由 `Party.team_systems()` 判定，T2.2 已交付）；三态**效果内容**以本章为准——原被动数值加成（atk+10% 等）**作废**（见 §9 C15）。

### 4.1 共振（全员同系）

| 项 | 规则 |
| --- | --- |
| 触发条件 | 战斗中**三名角色都释放过大招**后自动触发（计数窗口与循环规则见 §9 C10） |
| 合击技 | **三人合击技**：不看跑条，触发瞬间插入释放（不占任何角色行动轮次，不等待速度条；与 §2.2 后台跑条/演出暂停规则衔接）；合击触发后三人速度条位置与充能的处理见 §9 C10 |
| 合击演出 | 播放**合击 CG**（全屏；占位阶段=色块动画+合击技名大字，正式 CG 走 ArtProvider.get_skill_fx） |
| 目标 | **全体敌人** |
| 伤害 | **三人攻击力之和 × 100%**（合击倍率 100%，可调归数值策划） |
| 暴击 | **可暴击**：合击暴击率 = **三人暴击率之和 ÷ 300%**（例：三人各 20% → 20%）；合击暴击伤害 = **固定 300%**（固定值，不受爆伤词条/星髓爆伤加成影响） |

### 4.2 汇流（两系混编）

| 项 | 规则 |
| --- | --- |
| 单体效果 | 角色**单独释放大招后**，该角色大招充能条**自动充能 30%**（释放后充能条不归 0，而置为充能上限的 30%；上限属性化口径见 §9 C13） |
| 全体效果 | **三人（全队）都释放过大招后**，全体我方**拉条 30%**（速度条位置 +30）；拉条细则（是否可立即触发出手、与演出暂停衔接）见 §9 C11 |
| 计数口径 | 「三人都释放过大招」的计数窗口与共振同口径（§9 C10） |

### 4.3 混元（三系齐全）

| 项 | 规则 |
| --- | --- |
| 效果 | 全队角色**全属性增幅 30%**，进战斗时生效、持续整场 |
| 属性范围 | 「全属性」的界定（四维 hp/atk/def/spd 是否含暴击/爆伤/充能效率）见 §9 C12 |

### 4.4 生效时点与叠加

1. 体系判定进战斗时确定，战斗中编队不变则体系效果不变。
2. 混元全属性增幅在星髓属性**并入之后**按百分比放大（先加算后乘算，最终口径待数值确认）。
3. 共振合击伤害是否吃星髓 3 件套条件增伤等乘区——见 §9 C14。
4. 敌人无体系效果。

## 5. 属性与星髓加成

1. 角色与敌人的战斗属性均有**初始值**（hp/atk/def/spd 等，来自 characters.csv / enemies.csv）。
2. 战斗时**角色属性叠加星髓加成**（装备属性并入面板，进战斗带入）：
   - **速度**：星髓速度词条 → 速度条前推速率加成（§2）；
   - **充能**：星髓充能词条 → 充能条积累效率加成（§3；此即星髓系统文档 §8 C4 的消费点，本规则落地后该项待定解除）；
   - 攻击/防御/血量/暴击/爆伤：常规并入伤害与生存属性。
3. 星髓套装效果（2件套数值/3件套条件增伤）战斗结算时生效（接口见星髓系统文档 §7.1）。
4. 敌人无星髓，仅初始属性 + AI 机制。

- 本文件只定**机制结构与 UI/演出规格**；数值归数值策划：充能积累量与途径数值（C4）、技能 power 倍率（沿用 T2.1）、敌人双技能数值（T3.1）、速度条平局与轮次参数（C8）、合击倍率与暴击参数（C10/C14）、混元增幅范围（C12）。
- 数值落位：skills.csv / enemies.csv / characters.csv，禁止硬编码。
