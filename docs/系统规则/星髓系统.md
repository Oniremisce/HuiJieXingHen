## 1. 定位与获取

| 项    | 规则                                                      |
| ---- | ------------------------------------------------------- |
| 定位   | 类似角色装备的**特殊物品**；获取后在**角色面板 → 星髓面板**查看，**不登记到背包**        |
| 获取途径 | 打怪战斗掉落、剧情奖励等（MVP 先实现战斗掉落 + 剧情奖励两类）                      |
| 固定性  | 每枚星髓的**套装与槽位获取时固定，永不变更**（例：获得「套装1·6号位」星髓，它永远是套装1的6号位星髓） |
| 堆叠   | 同（套装, 槽位, 词条组合）的星髓可持有多枚，逐枚独立（各自强化等级/副词条进度独立）            |

## 2. 槽位与装备规则

1. 每个**实机角色**（可用于战斗的角色：入队角色、试用角色）拥有 **6 个星髓槽位**：1号位 \~ 6号位，一一对应，不可混用（1号位星髓只能装 1号位槽）。
2. **入队角色**：可在角色面板自由装备、卸下、搭配星髓（《初期设定》：星髓可自由卸下，方便尝试不同套装组合）。
3. **试用角色**（心契任务、剧情任务临时入队）：由**系统默认配置固定的一套星髓**，玩家不可更换（试用结束后配置随角色回收，不落入玩家持有）。
4. 槽位与词条强关联：1/2/3号位主词条固定，4/5/6号位主词条随机（见 §4）。

## 3. 套装与套装效果

### 3.1 套装结构

- MVP 先做 **2 个套装**：套装1、套装2（正式名称待定）。
- **每个套装完整包含 1\~6 号位**共 6 种星髓。
- 后续可添加更多套装（结构不变，只增 `set_id` 行）。

### 3.2 套装效果激活规则

| 装备同套件数 | 效果                                    |
| ------ | ------------------------------------- |
| 2 件    | 激活 **2件套数值加成**                        |
| 3 件    | 同时激活 **2件套加成 + 3件套加成**                |
| 3 件以上  | 不额外叠加；6 件同套只触发一次 2件套 + 一次 3件套（《初期设定》） |

- 6 个槽位可自由组合：**3+3**、**2+2+2** 等；套装效果只与**装备件数**有关，与具体槽位无关。
- MVP 套装属性：

| 套装      | 2件套加成   | 3件套加成                      |
| ------- | ------- | -------------------------- |
| **套装1** | 暴击 +15% | 攻击**血量 > 70%** 的敌人时，增伤 50% |
| **套装2** | 爆伤 +15% | 攻击**血量 < 50%** 的敌人时，增伤 50% |

> 3件套为**条件增伤**：判定时机=伤害结算时目标当前 HP 占其 max\_hp 的比例（>70% 严格大于；<50% 严格小于）；增伤作用于最终伤害乘区（接口见 §7.1）。

## 4. 词条系统

### 4.1 词条类型总表（7 种）

| 词条    | 类型           | 说明               |
| ----- | ------------ | ---------------- |
| 攻击    | 固定值          | 只作 1号位主词条        |
| 防御    | 固定值          | 只作 2号位主词条        |
| 血量    | 固定值          | 只作 3号位主词条        |
| 百分比攻击 | 百分比          | 主词条（4/5号位池）/ 副词条 |
| 百分比防御 | 百分比          | 主词条（4号位池）/ 副词条   |
| 百分比血量 | 百分比          | 主词条（4号位池）/ 副词条   |
| 暴击    | 百分比（暴击率）     | 主词条（5号位池）/ 副词条   |
| 爆伤    | 百分比（暴击伤害）    | 主词条（5号位池）/ 副词条   |
| 速度    | 固定值          | 主词条（6号位池）/ 副词条   |
| 充能    | 百分比（见 §8 C6） | 主词条（6号位池）/ 副词条   |

### 4.2 主词条规则

| 槽位  | 主词条                        |
| --- | -------------------------- |
| 1号位 | **固定=攻击**                  |
| 2号位 | **固定=防御**                  |
| 3号位 | **固定=血量**                  |
| 4号位 | 随机其一：百分比攻击 / 百分比防御 / 百分比血量 |
| 5号位 | 随机其一：暴击 / 爆伤 / 百分比攻击       |
| 6号位 | 随机其一：充能 / 速度               |

- 主词条数值随强化等级成长（成长曲线数值归数值策划，T2.8/T6.5）。

### 4.3 副词条规则

1. 每枚星髓最多 **5 条副词条**，词条从 7 种池（百分比攻击/百分比防御/百分比血量/暴击/爆伤/速度/充能）中选取，**5 条互不相同**。
2. **初始 0 级无生效副词条**；每强化 2 级觉醒 1 条：+2/+4/+6/+8/+10 分别解锁第 1\~5 条（《初期设定》：随机觉醒、不重复、数值固定不浮动、出现概率均分）。
3. 副词条与主词条可同类型叠加（如 5号位主词条=暴击，副词条也可觉醒出暴击，两处数值分别生效后合计）。

## 5. 强化养成

| 项   | 规则                               |
| --- | -------------------------------- |
| 等级  | 初始 **0 级**，满级 **+10**            |
| 消耗  | 星髓强化材料（获取：战斗掉落/任务奖励；具体消耗数值归数值策划） |

## 7. 系统接口

### 7.1 战斗结算（T3.4 伤害公式扩展点）

- 星髓属性并入角色面板属性（攻击/防御/血量/暴击率/爆伤/速度/充能），进战斗时由面板属性带入 BattleUnit。
- 现行公式 `damage = max(1, atk * skill_power - def)` 需增加**最终增伤乘区**：`damage = max(1, (atk * skill_power - def)) * (1 + 条件增伤)`——套装 3 件套条件增伤在此判定（目标 HP 比例 >70% / <50%）。
- 暴击判定沿用 T3.4（基础暴击率 10% + 星髓暴击词条加成；暴伤 ×1.5 + 爆伤词条加成）。
- 速度词条 → T3.2 行动排序 spd 加成；充能词条作用见 §8 C6。
