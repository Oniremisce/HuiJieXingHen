## 一、游戏定位

- **类型**：单机剧情驱动游戏，融合「暗色幻想回合制」与「生活模拟」。
- **画面风格**：
  - 2.5D Q 版地图探索
  - Q 版角色
  - 二次元美少女动态立绘
  - 高清 UI
- **内容更新方式**：剧情以「星历篇章」形式持续更新，类似二游版本迭代，但**全程离线、无内购**。
- **唤星系统**：内置「唤星」抽卡模拟系统，所有唤星资源均可通过游玩获得，满足抽卡欲望与出金惊喜。
- **无家园系统**：本作不设家园系统，原家园事件、生活事件均统一并入「日常事件」。

## 二、世界观

虚海深处存在三个界泡：

| 界泡 | 名称 | 法则 |
| --- | --- | --- |
| 铸星机界 | 索恩 | 科技与机械法则主导 |
| 虹渊法界 | 艾瑟兰 | 魔法与元素法则主导 |
| 九霄玄界 | 太微 | 修仙与灵脉法则主导 |

某日，三个界泡因未知牵引发生「融合」：

- 世界彼此重叠、融合，山河崩解，生灵异变，旧有秩序崩裂。
- 各方对此有不同解读：
  - 玄门称之为**天道异变**；
  - 机律称之为**底层协议污染**；
  - 秘法称之为**大源回响**。
- 三界通道「界隙」被打通。
- 融合后诞生的新力量「**虚熵**」开始污染现实，催生出名为「**灾蚀**」的怪物。

为求生路，三界成立「**汇界盟约**」：机律联邦、秘法评议会、太微仙盟开始合作，共同抗击灾蚀。

### 天衡与觉醒者

- **天衡**：三界融合不完全的天道。
- 天衡残存的自保本能化作规则，可使心灵纯净的少女觉醒「**天心印记**」，她们被称为「**觉醒者**」。
- 觉醒者能够驾驭虚熵、净化灾蚀，成为三界对抗灾难的核心力量。
- 设定上觉醒者绝大多数为少女，不额外解释原因。

### 主角

- 主角是一名从无虚熵世界意外穿越而来的「**异乡人**」。
- 最初只想混吃等死，在结识一位位觉醒者少女、经历无数战斗后，逐渐成长为带领她们抗击灾蚀、拯救汇界的核心人物。
- **不参与战斗系统**：主角不是觉醒者。
- **天衡赐福**：主角拥有回溯时间的能力，因此带领觉醒的少女们在**九万次失败的未来**中找出唯一的生路。
- **最终目标**：助天衡完成融合，重塑世界——完美融合魔力、灵气与数率（科技文明底层数理规则），把虚熵改变为三界通用的力量，让灾蚀不再诞生。

## 三、角色获取与招募

角色入队分为三步：

1. **剧情邂逅**：主线、支线或日常事件中认识角色。
2. **心契任务**：
   - 结识角色后开启该角色的心契任务线。
   - 心契任务中，该角色以「**同行**」状态临时加入队伍，可试用、参与战斗、共同探索、触发剧情。
   - 通过共同探索、赠礼、编队战斗、日常事件互动推进任务。
   - 完成当前角色心契任务后，即视为**心契满阶**。
3. **正式招募**：心契满阶后，使用唤星获得的「**星缘令**」招募入队。

**招募限制**：未满足「剧情邂逅 + 心契任务完成」时，即使拥有星缘令也无法招募，避免跳过剧情与人物塑造。

## 四、唤星系统

- **卡池**：不区分卡池，只有**通用池**。
- **消耗资源**：可肝资源「**星砂**」。
- **抽取内容**：
  - 星缘令
  - 随机角色 CG
  - 角色养成材料
  - 星髓
  - 星髓养成材料
- **出金内容**：星缘令、角色 CG。
  - 角色 CG 无实际用处，仅用于收藏和观看。
  - 使用星缘令解锁角色。
- **无真实货币内购**，出金惊喜保留。
- 所有星砂、星缘令均可通过**探索、日常、任务、战斗与章节奖励**获得。
- **抽取方式**：单抽（星砂×100）与**十连**（星砂×1000）；十连一次扣除、连抽 10 次、结果统一展示；保底计数跨抽持续生效。
- **唤星界面**（全屏展示）：**右上角**常显**星砂数量**（实时刷新）；界面主体为**角色展示图**；**右下角**并排「**单抽**」「**十连**」两个按钮（星砂不足时对应按钮禁用并提示）。
- **抽卡演出**：抽取播放**抽卡动画**；十连结果页**竖向并排**展示全部抽取物；单抽/十连结果中包含**星缘令**时播放**特殊动画**；结果中包含**角色 CG**时**播放一次该 CG**（全屏展示）。

## 五、战斗系统

- **战斗形式**：Q 版三人小队战斗。
- **角色体系**：机律 / 秘法 / 玄门（体系特色、角色阵营与技能设定详见《系统规则·角色系统》；混元=三系齐全的队伍状态，判定与效果见《队伍系统》与《战斗系统》）。

### 队伍机制

- **共振**：编队所有角色为**相同体系**时触发。
- **汇流**：编队角色为**非相同体系**，且**未集齐**机律、秘法、玄门三种不同体系时触发。
- **混元**：编队**集齐**机律、秘法、玄门三个不同体系时触发，**不触发**共振和汇流。
- **三态效果**（机制细则见《系统规则·战斗系统》§4）：共振=三人都释放大招后自动释放三人合击技（全体敌人伤害，可暴击）；汇流=角色释放大招后自动充能 30%，三人齐后全体拉条 30%；混元=全队全属性增幅 30%。

### 战斗操作与界面

- 战斗界面**右上角**提供**自动/手动战斗切换**（MVP 默认自动）；手动模式下轮到我方出手时，右下角立绘下方显示**小技能/大招按钮**（快捷键 E/Q）。
- **速度条**位于屏幕**左侧**（竖向进度条，高度为屏幕竖向的三分之一，跑条方向**自上而下**），我方与敌人的**圆形小头像**在条上跑动，跑条过程以**动画**呈现；屏幕**左下角**横排 3 个**角色信息板块**（头像+角色名+血条数字+buff 图标+等级，互不重叠）；我方角色头顶**体系图标+血条**常显、敌方头顶**血条**常显；对阵棋盘格仅为站位逻辑，UI 不显示。
- 进入战斗双方按**对阵阵型**布置：我方 3 人在屏幕中间左下角、敌方在屏幕中间右上角（4×3 斜向格子阵地，敌方最多 6 人，模型与地图 Q 版角色同规格）。
- 释放技能进入**目标选择**：敌方头顶向下箭头指示目标，移动键切换；攻击范围（单体/整列/全体等）由角色技能设定定义。
- 攻击造成伤害时，敌方头顶显示**伤害飘字**。

### 战斗演出

- 小技能释放时右下角常驻立绘**切换为技能释放动态立绘**。
- 大招与三人合击技播放**全屏技能 CG**。
- 战斗表现兼顾 Q 版战场与高清立绘，形成「**Q 版世界 + 高精度角色**」的反差。

## 六、养成与数值

### 人物升级

- 提升基础属性与技能等级。

### 星髓系统

- 每名觉醒者拥有 **6 个星髓槽位**，可装备 6 枚星髓。
- **星髓来源**：
  - 界隙结晶
  - 灾蚀兽核心净化后的天衡残片
  - 三界融合时残留的虚熵回响
- 每枚星髓满级为 **+10**，拥有：
  - **1 条固定主词条**；
  - **5 条副词条**。

#### 副词条觉醒规则

- 星髓每提升 **2 级**，从未解锁的副词条中**随机觉醒 1 条**。
- 副词条**不会重复抽取**，分别在 **+2、+4、+6、+8、+10** 时解锁。
- 副词条数值**固定，不随机浮动**，出现概率均分。

#### 星髓套装效果

- 每枚星髓属于一个星髓套装。
- 装备同套装星髓时，按件数激活套装效果：

| 件数 | 效果 |
| --- | --- |
| 2 件套 | 装备同套星髓 2 枚时激活 |
| 3 件套 | 装备同套星髓 3 枚时激活，并同时享受该套装的 2 件套效果 |

**规则说明：**

- 3 件以上同套**不额外叠加**；6 件同套也只触发**一次** 2 件套与**一次** 3 件套。
- 6 个槽位可自由组合，例如 **3+3**、**2+2+2**。
- 套装效果只与**装备件数**有关，与具体槽位无关。
- 星髓可**自由卸下**，方便玩家尝试不同体系与套装组合。

- 所有星砂、星缘令均可通过**探索、日常、任务、战斗与章节奖励**获得。

## 八、剧情演出系统

### 1. 地图探索与对话触发

- 玩家操控人物在 2.5D Q 版地图中自由走动。
- **地图包括**：汇界营地、索恩机城、艾瑟兰虹域、太微仙山、界隙侵蚀区等。
- 靠近 NPC 时，角色头顶出现交互提示，按键触发对话。
- **触发方式**：
  - 主线剧情：到达指定区域或靠近事件点触发。
  - 支线、心契任务、日常事件：与特定角色对话触发。

### 2. 文字对话与立绘表现

- 对话采用**对话窗**，以文字推进。
- 对话窗显示：**角色姓名、所属阵营、台词内容**。
- 支持：**逐字显示、自动播放、快进、历史回顾、跳过已读**。
- **立绘表现**：
  - 主要人物对话时，对话框旁显示高清人物立绘，采用**二次元动态立绘**，可随情绪切换**表情差分**。
  - 普通汇界居民可使用简化头像或半身像。
  - 重点角色使用完整动态立绘。

### 3. 剧情事件类型

| 事件类型 | 说明 |
| --- | --- |
| 主线事件 | 推进星历篇章，揭示三界融合、界隙、天衡、觉醒者与灾蚀真相 |
| 支线事件 | 了解三界融合后的日常生活与冲突 |
| 心契任务 | 与觉醒者共同探索、赠礼、编队战斗、日常事件互动后触发，完成后心契满阶；任务中角色以同行状态提供试用 |
| 日常事件 | 根据时间、章节、天气触发角色日常对话 |
| 随机事件 | 地图走动时靠近特定地点或角色触发，可获得星砂、星髓、养成材料等 |

### 4. CG 穿插：星痕绘卷

- 关键剧情节点穿插**全屏高清 CG**，称为「**星痕绘卷**」。
- 示例场景：界泡融合爆发、界隙开启、天心印记觉醒、灾蚀攻城、三界盟约签署、角色心契任务完成、星历篇章高潮。
- 星痕绘卷可在**回顾系统**中重新观看，并附带**剧情注释**与**角色档案**。

### 5. 与招募、战斗、养成的衔接

- 剧情演出是角色入队的前置条件：
  1. 地图漫游中**剧情邂逅**角色；
  2. 完成该角色的**心契任务**，将心契提升至满阶；
  3. 使用唤星获得的**星缘令**正式招募。
- 唤星系统**不会跳过剧情与人物塑造**，只作为抽卡模拟器满足抽卡欲望与出金惊喜。
- 战斗中小技能切换角色动态立绘，大招与合击技播放全屏 CG；**剧情立绘与战斗立绘资源互通**。
