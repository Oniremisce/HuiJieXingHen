### 1.4 色彩红线（沿用 T1.6，新增两条）

1. 新实体避开：玩家黄 `#FFEB4D`、地面 `#8CA08C`、障碍 `#3F475B` 三色。
2. **金系仅任务/奖励语义**（金菱形、任务追踪图标），禁止用于普通 NPC/装饰。
3. **青白系仅"星光/神像/结晶"语义**（`#CFF6FF`/`#7FDFFF`），机律科技青 `#4FC3E8` 不得混用于星光物件。

## 2. 箱庭图视觉建议（M 键全屏浮层）

### 2.1 暗底与线框

| 项 | 建议 | 理由 |
| --- | --- | --- |
| 暗底 | 全屏 `Color(0.04, 0.05, 0.07, 0.72)`（≈`#0A0C12` @ 72% 不透明度） | 线框可读的同时残留地面轮廓感；禁用 100% 纯黑（丢失空间参照） |
| 线框描边 | `#E8ECF2`（冷白）1.5px，不随缩放变粗（screen-space 线宽） | 与暗底对比度 > 12:1；冷白比纯白柔和、与描边 shader 纯白形成"地图/场景"语境差 |
| 绘制层级 | 暗底 → 线框 → 标注（主角 > 任务 NPC > 神像 > 出口，重叠时按此上层优先） | — |

### 2.2 标注图形语义（形状+颜色双编码，色弱可辨）

| 标注 | 图形 | 颜色 | 尺寸 |
| --- | --- | --- | --- |
| 主角点位 | 实心等腰三角箭头（可带朝向旋转） | **玩家黄 `#FFEB4D`** + 1px 白描边 | 底 12px × 高 14px |
| 任务相关 NPC | 实心菱形（方块旋转 45°） | **琥珀金 `#F0B429`** + 1px 白描边 | 10×10 |
| 神像（已点亮） | 实心圆点 + 外圈光环 | 青白 `#CFF6FF`，光环 40% 透明同色 | 圆点 8px、外圈 16px |
| 神像（未点亮） | 同形状实心圆点 | 中灰 `#6B7280` | 8px |
| 场景出口 | **空心**菱形（仅描边） | 蓝灰 `#8CA6D1`（与 Building2 同系）1.5px | 12×12 |

> 关键区分：主角黄三角 vs 任务金菱形——`#FFEB4D` 与 `#F0B429` 明度差约 18%，加"三角/菱形+白描边"双编码确保不混淆；金 `#F0B429` 比调试触发区黄 `#FFD24D` 更深，因触发区产品态不可见，无实际冲突。

## 3. 遮挡描边验收建议（§5.5 基准：纯白 1.5~2px）

1. **宽度取值**：默认 **1.5px** 基准；验收在两种底色下走查——深底（Building2 蓝灰暗面 `#405273`、障碍 `#3F475B`）白描边对比充分；浅底（广场 `#D9C79E`、草地 `#8CA08C`）对比下降，**若 1.5px 在浅底肉眼难辨，允许升至 2px 上限**，不超 2px（再宽会描边喧宾夺主）。
2. **可辨识度标准**（验收截图需覆盖三态）：① 全遮挡（角色完全在 Building 后）轮廓完整可辨；② 半遮挡（约 50% 重叠）被挡边缘出描边、未挡部分正常；③ 移开后描边完全消失无残留。判读基准：0.9 zoom、1152×648 视口下截图放大 200% 仍可辨轮廓即合格。
3. **淡入淡出**：时长 **0.15~0.2s**（建议 0.18s）——<0.1s 贴墙移动会频闪，>0.3s 会有描边残影迟滞；用**遮挡面积比例连续驱动 alpha**（smoothstep 曲线），不要布尔硬切，角色沿建筑边缘平移时描边应平滑增减。
4. **纯白 `#FFFFFF` 外描边**（轮廓向外扩 1.5~2px），不混角色色/底色，玩家与 NPC 同参数。

## 4. 常驻 HUD 四区布局建议（CanvasLayer，独立于 Y-sort）

统一内边距：四边 **16px**；四区互不重叠，中央顶部留给场景视野。

```
┌─[16px]──────────────────────────────────────────────┐
│ A 左上区                              B 右上区 [16px] │
│  主角命名（20px 白字+深描边）          小地图 128×128  │
│  编队头像行 36×36 ×3 + 同行槽（间距8px）  （暗底同箱庭） │
│  任务追踪 1 条（金菱形图标+单行文本）                   │
│                                                     │
│                  （场景视野）                         │
│                                                     │
│            C 底部交互提示位（距底 48px）               │
│  D 底部按键提示条（距底 16px，首进 8s 后淡出）  [16px]  │
└─────────────────────────────────────────────────────┘
```

| 区 | 内容与参数 |
| --- | --- |
| A 左上 | 主角命名：占位「异乡人」，20px `#F5F5F5` + 描边/投影 `#20242E`；头像行：36×36 色块头像（§1.3）、间距 8px、同行槽虚线框；任务追踪：头像下 12px，**金菱形 10px 图标**（与箱庭图任务语义一致）+ 单行 14px `#E8ECF2`，超长省略号 |
| B 右上 | 小地图 128×128：暗底/线框/标注配色直接复用 §2（箱庭缩略），右/上缘各留 16px |
| C 底部交互提示 | 复用 Interactable 提示样式（白字+深底 `#20242E`），**水平居中、距底 48px**——给按键条让位且不挡角色脚下交互区 |
| D 底部按键条 | 键位胶囊：1px 描边 `#6B7280`、字 `#F5F5F5` 12px，序：B 背包 / C 角色 / G 唤星 / J 任务 / M 箱庭图 / Esc 导航；距底 16px 水平居中；**首进场景显示 8s → 0.5s 淡出**（淡出时长建议 0.5s） |
| 层级 | HUD 独立 CanvasLayer（不参与 Y-sort，按卡）；交互提示（C）z 高于按键条（D）；面板开关统一 ui_open/ui_closed + PauseManager |
