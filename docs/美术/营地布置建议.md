# 《汇界星痕》营地布置建议（T1.6 美术协作交付）

> 岗位：美术01 · 交付性质：布置建议（视觉区分色 + 占位形态），供系统程序布置 CampMap
> 依据：推进表 T1.6 完整指令、《交互系统》§5.3（B 类触发区）、TestMap 已有占位先例（T1.2/T1.5）
> 配套：《tileset占位规范.md》（地面/障碍色与 tile 硬约定）

***

## 1. 总原则

1. 延续 TestMap 占位形态：**Node2D + Polygon2D 等距色块**做房屋/树（Y-sort 实体，origin 在脚底），不用 Control 节点。
2. 一物一色系、明度分面：等距方块的顶面最亮、左/右侧面渐暗（同色系 3 档），玩家一眼可辨"类别"。
3. 交互物（NPC/拾取点）用**高饱和色**，与低饱和地面拉开；玩家黄色 `#FFEB4D` 是全场唯一黄，其余实体避开黄系。
4. 立体感的假等距三面色拆法沿用 Building1 先例：顶面 / 左面(+0.18 明度差) / 右面(-0.18 明度差) 同色系。

## 3. 布置要点（供参考，位置以系统程序实测通过为准）

- **广场开阔区**：地图几何中心附近留 ≥ 6×6 无障碍格；3 名觉醒者呈三角分散站位（两两间距 ≥ 3 格，检测区 r60+8 不重叠为佳）。
- **房屋 2~3 栋 + 树 4~6 棵**：沿广场外围摆放，与障碍围墙之间留 ≥ 1 格通行走廊；实体格下不叠障碍砖（防"视觉可走、物理挡人"误导）。
- **主线触发区**：覆盖广场入口走廊（B 类，body_entered → `interact_requested` + meta `main_trigger`，单次触发）；触发区路径上不放障碍与交互物。
- **拾取点**：1 个，放广场边角或房屋旁空地；挂 Interactable（action_type 建议 "open" 占位或按系统程序定），拾取反馈"消失 + 入背包"。
- **头顶名字标签**：沿用 Interactable HintRoot 样式——白字 `#F5F5F5` + 深底/描边 `#20242E`，z_index=100、不参与 Y-sort；名字"待定"，npc_id 用推进表给定三值。
- **色彩红线**：所有新实体避开玩家黄 `#FFEB4D`、地面 `#8CA08C`、障碍 `#3F475B` 三色；同屏同类元素配色一致（树都是同一绿）。
